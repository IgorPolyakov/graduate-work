DISPLACEMENT VECTOR FIELD, STRAIN COMPONENTS, SUB-PIXEL ACCURACY

The aim of this work is the development of software (SW) for evaluating deformations of solid surfaces, as well as conducting research on algorithms and methods using both model and real optical images.

The influence of the image interpolation method with sub-pixel accuracy is studied when using an iterative approach to constructing the displacement vector field (optical flow).

The project was implemented using the following development tools: the programming language C++ (Qt), the Qt Creator 3 development environment, and TeXstudio 2; the Git version control system.

Software developed in this work is presented in the appendix.
